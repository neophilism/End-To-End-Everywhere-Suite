ENGINEERING TRANSPARENCY

Build status isn't the same as security assurance.

GitHub Actions can show whether the code builds and its automated tests pass. That does not establish E2EESA conformance, device-key security, resistance to advanced attacks, independent cryptographic review, or production availability.

The architecture standard is maintained separately from this implementation. Features must state their actual security properties and limitations.
